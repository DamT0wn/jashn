## Changes description
Jashn helps organizers plan celebrations with a structured brief, budget ledger,
timeline, vendor checklist and ideas. The prototype uses explicitly labeled mock
planning output. Organizers review and accept drafts, edit records and track costs.
The static festive interface supports mobile layouts. Replanning and version
history are in progress and must pass their gate before being described as complete.

## Gen AI disclosure
This prototype currently uses a deterministic local mock provider. No live Gen AI
service is called in the demonstrated mock mode. A Vertex AI adapter is prepared
but has not been live-verified. Do not describe mocked output as live Gemini output.
